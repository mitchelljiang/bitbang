# Binary and hexadecimal

## Intro
Each bit has a place value that is a power of two, and the number is the sum of the place values of the bits that are 1. Hexadecimal writes every group of four bits as one digit, 0 to F. Click the bits, or type a value.

Representing numbers

Each bit has a place value that is a power of two, and the number is the sum of the place values of the bits that are 1. Hexadecimal writes every group of four bits as one digit, 0 to F. Click the bits, or type a value.

178 = 128 + 32 + 16 + 2. In hex, each group of four bits is one digit: 1011 0010 is 0xB2.
